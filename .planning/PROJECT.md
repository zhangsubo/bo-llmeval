# LLM API 服务评测管理平台

## 这是什么

LLM API 服务评测管理平台是一个内部生产准入与供应商横向选择的客观评测工具。平台统一管理供应商连接、模型部署和测试资源，在一致条件下验证协议兼容性、稳定性、性能、成本和基础模型能力，并生成可复现的离线报告。服务于内部评测人员、供应商管理人员和技术人员。

## 核心价值

在相同测试输入、参数、负载和 Tokenizer 口径下，客观横向比较供应商 LLM API 服务的性能、质量和成本，为生产准入提供可复现证据。

## 业务背景

- **客户**：内部评测人员、供应商管理人员、技术人员（通过可信网络访问）
- **业务价值**：降低供应商接入风险，统一评测口径，提升决策效率
- **成功指标**：
  - 新供应商接入到完成冒烟测试不超过 10 分钟
  - 使用模板创建多供应商评测任务不超过 5 分钟
  - 100% 的已启动任务可追溯配置快照

### 明确排除

- 客户自助测试 SaaS、公开排行榜、自动准入结论 — 首版仅服务内部
- Responses API、供应商原生协议、文本以外的模型类型 — 聚焦 Chat Completions
- 定时任务、公开 API、Webhook、外部消息通知 — 首版无自动化集成
- 主观写作评测、LLM-as-a-Judge、Agent 工具执行 — 仅客观评分
- 全量搬运 OpenCompass/EvalScope 数据集 — 按需精选
- 暂停续跑、断点续跑、性能请求自动重试 — 保留真实失败率
- Redis、Celery、Elasticsearch、Kubernetes — 技术栈最小化
- 在线分享链接、报告托管、多语言和移动端适配 — 首版桌面 Chrome

## 背景

- **技术环境**：Python/FastAPI 后端，React/TypeScript 前端，PostgreSQL 数据库，EvalScope 评测引擎
- **容量基准**：约 30 家供应商、500 条连接、2,000 个模型部署、10,000 个历史任务、10,000,000 条请求记录
- **部署环境**：Docker Compose，外部 PostgreSQL，持久化报告和缓存目录
- **已有工作**：PRD v1.0 已确认，包含完整功能清单、指标口径、安全要求和验收用例

## 约束

- **协议**：仅支持 OpenAI-compatible Chat Completions（流式/非流式），认证方式仅 Bearer API Key
- **网络**：仅通过可信内网、VPN 或统一网关访问，生产部署不得直接暴露公网
- **安全**：API Key 应用层加密存储，页面/日志/报告必须脱敏，代码执行在隔离沙箱
- **技术栈**：Python、FastAPI、React、TypeScript、PostgreSQL、EvalScope；不使用 Redis、Celery、K8s
- **性能**：常用列表和任务汇总接口 P95 不超过 2 秒，取消指令 5 秒内停止新请求
- **兼容性**：仅保证最新稳定版桌面 Chrome，不做移动端适配
- **时间线**：首版交付，后续 SSO、外部价格同步、LLM-as-a-Judge、多模态等功能待需求确认后立项

## 关键决策

| 决策 | 理由 | 结果 |
|------|------|------|
| EvalScope 作为唯一评测引擎 | 同时提供性能压测和客观质量评测，避免维护多套工具 | — 待验证 |
| PostgreSQL 作为队列和数据库 | 原生支持 SKIP LOCKED、JSON、分位数聚合，无需引入 Redis/Celery | — 待验证 |
| 双口径 Token 统计 | 供应商 usage 用于成本，本地 Tokenizer 用于性能对齐 | — 待验证 |
| 静态多页 HTML 报告 | 可离线查看、可删除敏感明细页、可人工外发 | — 待验证 |
| 首版无权限体系 | 仅内部可信网络访问，降低首版复杂度 | — 待验证 |
| 性能请求不自动重试 | 保留真实失败率和延迟分布 | — 待验证 |
