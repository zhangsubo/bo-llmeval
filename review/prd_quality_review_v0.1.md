# LLM API 服务评测管理平台 PRD 质量检查报告

> 审查对象：`prd/prd_v0.1_draft.md`  
> 审查日期：2026-08-18  
> 审查结论：产品方向与范围完整，可进入最终版；以下必要修订全部写回 v1.0。

## 1. 技术负责人视角

| 问题 | 影响 | 建议 | 写回 PRD |
|---|---|---|---|
| 创建任务、入队、取消、重试、报告生成和清理的重复点击规则不够具体 | 可能生成重复 Run、重复报告或状态竞争 | 所有变更操作增加幂等键/状态条件更新；执行中禁用重复按钮；取消可重复调用且结果一致 | 是 |
| API Key 不应进入普通任务快照，但需要证明执行时使用了哪个凭证版本 | 历史追溯不足或误存秘密 | 快照只保存 `credential_version`，不保存密文或明文；替换 Key 时阻断排队/运行任务 | 是 |
| DNS 校验与真正建立连接之间可能发生 DNS rebinding | 可能绕过白名单访问内部地址 | 每次新建连接池前重新解析并校验，将连接绑定到本次已校验地址；Host/SNI 仍使用原域名 | 是 |
| 模型输出直接嵌入 HTML 报告可能形成存储型 XSS | 打开静态报告时执行恶意脚本 | 所有 Prompt、回答、错误和扩展字段按纯文本转义；图表数据使用安全 JSON 序列化；禁止执行模型生成 HTML/JS | 是 |
| CSV 单元格可能触发表格公式注入 | 用户打开导出文件时执行危险公式 | 对以 `= + - @` 开头的文本字段做公式安全转义，同时保留 JSON 原值 | 是 |
| 历史清理同时涉及 PostgreSQL 和文件系统，无法用单事务保证 | 数据库与报告文件可能不一致 | 生成清理清单和清理批次；先标记清理中，再删除文件与业务记录；记录部分失败并允许按批次补偿重试 | 是 |
| 报告文件直接写正式目录时可能留下半成品 | 用户可能拿到损坏报告 | 在临时目录完整生成并校验后原子发布，失败不创建正式版本 | 已有，强化 |
| 任务容量很大，详情页可能误加载完整正文 | 页面、数据库和浏览器内存压力 | 请求列表强制分页，正文按单条懒加载，默认不查询大型原始 JSON | 是 |

## 2. 挑剔用户视角

| 问题 | 影响 | 建议 | 写回 PRD |
|---|---|---|---|
| 长任务创建表单容易配置中断 | 用户丢失已选目标和参数 | 新建即创建草稿；分步保存；离开页面可继续编辑 | 是 |
| 预检问题若只有“失败”结论，修复成本高 | 用户需要逐项猜测配置错误 | 按目标和检查项展示阻断/警告、原因、当前值、限制值及修复入口 | 是 |
| 列表缺少明确的搜索和筛选要求 | 二十余供应商和万级任务下定位困难 | 供应商、连接、模型、任务、报告支持关键词、状态、日期和关联对象筛选 | 是 |
| 取消、密钥替换、白名单修改、历史清理风险等级不同 | 确认方式可能过度或不足 | 普通取消使用确认弹窗；密钥替换和 TLS 例外二次确认；白名单与清理输入确认文本 | 是 |
| 无数据/失败页面未明确下一步 | 新用户不清楚如何继续 | 空状态提供创建供应商、下载资源、新建任务或重试入口 | 是 |

## 3. 运营负责人视角

| 补充项 | 价值 | 建议 | 写回 PRD |
|---|---|---|---|
| 操作与业务数据边界 | 避免把内部平台做成增长分析系统 | 首版仅保留审计事件和必要业务汇总，不引入第三方埋点或用户画像 | 是 |
| 价格与汇率有效性 | 防止错误成本比较 | 单价不得为负；汇率必须大于 0；任务显示价格来源和快照时间 | 是 |
| 历史筛选与导出 | 支持供应商复盘 | 任务/报告支持供应商、模型组、模板和日期筛选；导出仍为人工动作 | 是 |
| 备注版本可追溯 | 解释报告差异 | 报告版本记录备注快照，不修改历史报告 | 已有 |

## 4. 测试工程师视角

| 场景 | 预期 | 建议用例 | 写回 PRD |
|---|---|---|---|
| Base URL 编码、IPv6、用户名密码、混合斜杠和 DNS rebinding | 规范化或阻断，不能绕过白名单 | 增加 URL 信任边界测试矩阵 | 是 |
| SSE 空事件、半个 JSON、重复 `[DONE]`、流中断 | 准确分类并保留已收到内容 | 增加流式协议异常验收 | 是 |
| 重复点击入队、取消、重试、报告生成 | 不产生非预期重复副作用 | 增加幂等与状态竞争验收 | 是 |
| 100 MB 边界、非法 UTF-8、超长字段和部分坏行 | 整文件拒绝且提供定位 | 增加自定义数据集边界验收 | 是 |
| 清理与报告生成/下载并发 | 不清理活动资源；部分失败可恢复 | 增加清理并发验收 | 是 |
| 恶意 HTML/JS 模型输出和 CSV 公式 | 打开报告/CSV 不执行内容 | 增加 XSS 与公式注入验收 | 是 |
| 汇率为 0、负数或缺失 | 阻止保存或成本折算 | 增加价格字段边界验收 | 是 |
| Worker 失联后恢复并重复上报 | 旧 lease 不能覆盖新状态 | 增加 lease fencing 验收 | 是 |

## 5. 写回清单

- [x] 任务与高风险操作：补充幂等、状态条件更新和重复点击规则。
- [x] 连接安全：补充 DNS 重解析、已校验地址绑定和 URL 规范化规则。
- [x] 任务快照：使用 `credential_version`，不保存秘密。
- [x] 导出与报告：补充 HTML 纯文本转义、安全 JSON 序列化和 CSV 公式转义。
- [x] 历史清理：补充清理批次、部分失败和补偿重试。
- [x] 大数据详情：补充分页与正文懒加载。
- [x] 用户体验：补充草稿续编、可修复预检、搜索筛选和空状态。
- [x] 价格：补充单价和汇率校验。
- [x] 验收：新增流式异常、数据集边界、幂等、XSS/CSV 和清理并发用例。
